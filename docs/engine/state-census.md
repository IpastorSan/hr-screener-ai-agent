# Engine state census

Generated by `make replay` (`evals/replay/census.py`) from the replay corpus (`evals/replay/corpus.jsonl.gz`): every distinct `ConversationState` given to or returned by the engine while the journeys and the e2e personas run offline.

A combination is the `stage` plus the hidden flags set in the state: `outcome` with its value, the others when not at their default (`not_consented`: past the consent stage without consent). The example is the first journey (`group.id`) or persona (`e2e.id`) that reached it; `+derived` marks calls made on a recorded state that no journey makes (nudges, idle close, calendar cancellation; `record.derived`), `+synth.*` scripted extractions the offline extractor cannot produce (`evals/replay/synth.py`).

This is the version 1 view of the state, a `stage` plus flags, which the corpus records and the version 1 reader (`backend/src/sazon/engine/upgrade.py`) is tested against. The engine now keeps one `phase` instead (`backend/src/sazon/engine/state.py`); a state stored in that shape is written back as flags before it is counted.

The states as the engine declares them, with every transition between them, are in the statechart [states.mmd](states.mmd) (`make diagram`); `evals/replay/tests/test_transitions.py` checks the corpus takes those and only those.
